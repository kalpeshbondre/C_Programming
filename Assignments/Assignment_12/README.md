# Assignment 12 – Digit Operations and Frequency Counting

## Description

This assignment contains C programs based on digit extraction and frequency counting. The programs use arithmetic operators, loops, and conditional statements to extract digits from a number, check specific digit conditions, and calculate their frequency.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 12.1 | `DisplayDigit()` | Displays all digits of a number in reverse order. |
| Program 12.2 | `ChkZero()` | Checks whether a number contains the digit zero. |
| Program 12.3 | `CountTwo()` | Counts the frequency of digit 2 in a number. |
| Program 12.4 | `CountFour()` | Counts the frequency of digit 4 in a number. |
| Program 12.5 | `Count()` | Counts the frequency of digits less than 6 in a number. |

## Concepts Covered

- User-defined functions
- Function arguments and return values
- Digit extraction using modulus operator (`%`)
- Digit removal using division operator (`/`)
- `while` loop
- Conditional statements (`if`)
- Boolean data type (`bool`)
- Frequency counting using counter variables
- Early return from functions
- Negative number handling
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Arithmetic and relational operators

## Learning Objectives

- Understand how to extract individual digits from an integer.
- Learn to process digits using a `while` loop.
- Develop logic to check specific digits in a number.
- Calculate the frequency of digits based on given conditions.
- Understand Boolean functions and return values.
- Improve problem-solving skills through digit-based operations.
- Practice input validation and error handling in C.

## Technologies Used

- **Programming Language:** C
