# Assignment 26 – ASCII Values and Character Manipulation

## Description

This assignment focuses on ASCII character representation, character manipulation, and number system conversions in C. It includes programs to display ASCII values from 0 to 255, toggle the case of an alphabet, identify specified special characters, and display the decimal, octal, and hexadecimal representations of a character.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 26.1 | `DisplayASCII()` | Displays characters and their Decimal, Hexadecimal, and Octal values from 0 to 255. |
| Program 26.2 | `Display()` | Converts uppercase characters to lowercase and lowercase characters to uppercase. Other characters remain unchanged. |
| Program 26.3 | `Display()` | Displays the ASCII value of a character in Decimal, Octal, and Hexadecimal formats. |
| Program 26.4 | `ChkSpecial()` | Checks whether the given character belongs to the specified special-character set (`!`, `@`, `#`, `$`, `%`, `^`, `&`, `*`). |

## Concepts Covered

- ASCII character representation
- Character data type (`char`)
- Character manipulation
- Uppercase and lowercase conversion
- Character range checking
- Decimal number system (Base 10)
- Octal number system (Base 8)
- Hexadecimal number system (Base 16)
- Format specifiers (`%c`, `%d`, `%o`, `%X`)
- Character-to-integer conversion
- Arithmetic operations on characters
- Relational operators
- Logical OR (`||`)
- Boolean data type (`bool`)
- User-defined functions
- `for` loop
- Input validation using `scanf()`
- Formatted output using `printf()`

## Learning Objectives

- Understand ASCII character representation and numeric values.
- Display character values in different number systems.
- Convert uppercase alphabets to lowercase and vice versa.
- Identify specified special characters using logical conditions.
- Understand the relationship between characters and their integer representations.
- Use appropriate format specifiers for decimal, octal, and hexadecimal output.
- Apply character manipulation techniques using arithmetic operations.
- Develop modular programs using user-defined functions.
