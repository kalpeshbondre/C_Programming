# Assignment 7 – Looping Statements and Number Patterns

## Description
This assignment contains C programs designed to develop logical thinking and understand looping statements using `for` loops.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 7.1 | `Pattern()` | Displays `$` and `*` symbols N times. |
| Program 7.2 | `Display()` | Displays numbers from 1 to N. |
| Program 7.3 | `Display()` | Displays numbers from -N to N. |
| Program 7.4 | `OddDisplay()` | Displays all odd numbers from 1 to N. |
| Program 7.5 | `MultipleDisplay()` | Displays the first five multiples of a given number. |

## Concepts Covered
- `for` loop
- Loop initialization, condition and updation
- Increment operators
- Conditional statements
- Modulus operator (`%`)
- Input handling using `scanf()`
- Input updating
- Generating number sequences
- Displaying number patterns
- Finding multiples of a number

## Learning Objectives
- Understand the working of looping statements.
- Develop logic using counters and loop conditions.
- Generate number sequences using loops.
- Apply conditions inside loops.
- Improve problem-solving skills through C programming.

## Technologies Used
- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
