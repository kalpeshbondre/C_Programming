# Assignment 17 – Number and Alphabet Patterns

## Description

This assignment focuses on generating different number and alphabet patterns using nested looping statements and conditional statements in C. The programs display sequential numbers, even and odd numbers, alternating alphabets and numbers, positive and negative numbers, and incremental number patterns based on row and column positions.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 17.1 | `Pattern()` | Displays consecutive numbers from 1 to 9, repeatedly restarting from 1 after reaching 9. |
| Program 17.2 | `Pattern()` | Displays even numbers in odd-numbered rows and odd numbers in even-numbered rows. |
| Program 17.3 | `Pattern()` | Displays lowercase alphabets in odd-numbered rows and numbers in even-numbered rows. |
| Program 17.4 | `Pattern()` | Displays positive numbers in odd-numbered rows and negative numbers in even-numbered rows. |
| Program 17.5 | `Pattern()` | Displays incremental number patterns where each row starts with its row number. |

## Concepts Covered

- User-defined functions
- Function arguments and void return type
- Nested `for` loops
- Number pattern generation
- Alphabet pattern generation
- Odd and even number identification using modulus (`%`)
- Conditional statements (`if-else`)
- Character variables and character increment
- Positive and negative number patterns
- Row-wise and column-wise iteration
- Counter initialization and updation
- Variable reassignment based on row number
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Use of `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand nested looping statements for pattern generation.
- Develop logic for generating different number patterns.
- Apply conditional statements to control pattern variations.
- Understand odd and even row identification.
- Work with character variables to generate alphabet patterns.
- Generate positive and negative number sequences.
- Learn how to initialize and update counters based on row and column positions.
- Improve logical thinking and problem-solving skills using loops and conditions.
