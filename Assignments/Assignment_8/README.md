
# Assignment 8 – Conditional Statements and Looping

## Description

This assignment contains C programs designed to strengthen logical thinking and problem-solving skills using conditional statements, switch cases, loops, and mathematical operations.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 8.1 | `Number()` | Classifies a number as Small, Medium or Large. |
| Program 8.2 | `Display()` | Displays the word corresponding to a single digit. |
| Program 8.3 | `Factorial()` | Calculates the factorial of a given number. |
| Program 8.4 | `Table()` | Displays the multiplication table of a given number. |
| Program 8.5 | `TableRev()` | Displays the multiplication table in reverse order. |

## Concepts Covered

- `if`, `else if` and `else` statements
- `switch` statement
- `case` and `break`
- `for` loop
- Input validation using `scanf()`
- Input updating
- Factorial calculation
- Multiplication tables
- Reverse iteration
- `typedef` and `unsigned long long`
- Return values and function calls
- Integer overflow and data-type limitations

## Learning Objectives

- Understand conditional statements and switch cases.
- Develop logic using loops.
- Perform mathematical calculations using C.
- Work with different integer data types.
- Understand function-based programming.
- Improve input handling and problem-solving skills.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
