# Assignment 14 – Factor and Non-Factor Operations

## Description

This assignment focuses on factor and non-factor operations using user-defined functions and looping statements in C. The programs perform operations such as calculating the product of factors, displaying factors in reverse order, displaying non-factors, calculating the sum of non-factors, and finding the difference between the sum of factors and non-factors.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 14.1 | `MultFact()` | Calculates the product of all factors of a given number, excluding the number itself. |
| Program 14.2 | `FactRev()` | Displays all factors of a given number in reverse order, excluding the number itself. |
| Program 14.3 | `NonFact()` | Displays all non-factors of a given number. |
| Program 14.4 | `SumNonFact()` | Calculates the sum of all non-factors of a given number. |
| Program 14.5 | `FactDiff()` | Calculates the difference between the sum of factors and the sum of non-factors. |

## Concepts Covered

- User-defined functions
- Function arguments and return values
- `for` loop
- `if-else` conditional statements
- Modulus operator (`%`) for checking divisibility
- Identification of factors and non-factors
- Product of factors
- Reverse iteration
- Summation of non-factors
- Difference between two summations
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Positive number validation
- Arithmetic operations and relational operators

## Learning Objectives

- Understand how to identify factors and non-factors of a number.
- Apply the modulus operator to check divisibility.
- Calculate the product and sum of factors and non-factors.
- Display factors in reverse order using decrementing loops.
- Perform mathematical calculations using user-defined functions.
- Improve logical thinking and problem-solving skills.
- Understand the use of function return values.
