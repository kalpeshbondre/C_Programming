
# Assignment 9 – Patterns and Mathematical Operations

## Description

This assignment contains C programs designed to strengthen logical thinking and problem-solving skills using loops, conditional statements, mathematical operations, and user-defined functions.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 9.1 | `Display()` | Displays N stars (`*`) followed by N hash (`#`) symbols. |
| Program 9.2 | `DollarToInr()` | Converts US Dollars into Indian Rupees using a fixed conversion rate of ₹70 per USD. |
| Program 9.3 | `EvenFactor()` | Calculates the multiplication of all even numbers from 1 to N. |
| Program 9.4 | `OddFactor()` | Calculates the multiplication of all odd numbers from 1 to N. |
| Program 9.5 | `FactorialDiff()` | Calculates the difference between the multiplication of even and odd numbers. |

## Concepts Covered

- User-defined functions
- Input and output operations
- Input validation using `scanf()`
- `if` statements
- `for` loop
- Even and odd number operations
- Multiplication of even and odd factors
- Mathematical calculations
- Input updating
- Return values and function calls
- Integer data types and limitations

## Learning Objectives

- Understand function-based programming in C.
- Develop logical thinking using loops and conditions.
- Perform mathematical calculations using C.
- Calculate the multiplication of even and odd numbers.
- Understand the difference between even and odd products.
- Improve input handling and problem-solving skills.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
