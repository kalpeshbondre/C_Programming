# Assignment 4 – C Programming

## Description
This assignment contains C programs developed to practice functions, conditional statements, comparison operators, and arithmetic operators.

## Programs

| Sr. No. | Program Name | Description |
|:---:|---|---|
| 1 | CheckNumber | Checks whether a given number is positive, negative, or zero. |
| 2 | CheckEvenOdd | Determines whether a given number is even or odd. |
| 3 | FindGreater | Compares two integers and displays the greater number or indicates if both are equal. |
| 4 | CheckVotingEligibility | Checks whether a person is eligible for voting based on age. |
| 5 | CheckDivisibility | Checks whether a given number is divisible by 5. |

## Concepts Covered

- Functions
- Conditional statements (`if`, `else if`, `else`)
- Arithmetic operators (`%`)
- Relational operators (`>`, `<`, `>=`)
- Integer data type
- Function calling
- Standard input and output operations

## Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Code Editor:** Visual Studio Code
