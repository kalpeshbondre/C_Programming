# Assignment 23 – String Manipulation and Character Operations

## Description

This assignment focuses on string manipulation and character operations in C using character pointers. The programs perform operations such as converting strings to lowercase and uppercase, toggling character cases, displaying digits, and counting white spaces in a string.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 23.1 | `strlwrx()` | Converts all uppercase characters in a string into lowercase. |
| Program 23.2 | `struprx()` | Converts all lowercase characters in a string into uppercase. |
| Program 23.3 | `strtooglex()` | Toggles the case of alphabetic characters in a string. |
| Program 23.4 | `DisplayDigit()` | Displays all digit characters present in a string. |
| Program 23.5 | `CountWhite()` | Counts the total number of white spaces in a string. |

## Concepts Covered

- Character pointers and string traversal.
- NULL pointer checking.
- String termination using `'\0'`.
- Accessing and modifying characters using pointers.
- ASCII values of uppercase and lowercase alphabets.
- Converting uppercase characters into lowercase.
- Converting lowercase characters into uppercase.
- Toggling the case of alphabetic characters.
- Character filtering using conditional statements.
- Counting specific characters in a string.
- Returning values from user-defined functions.
- Error handling using return values.
- String input using `scanf()` with a scanset.

## Learning Objectives

- Understand how strings are accessed using character pointers.
- Learn to traverse strings using pointer increment operations.
- Perform character-level modifications without using library conversion functions.
- Apply conditions to identify specific character categories.
- Develop logic to filter and count characters in strings.
- Understand NULL pointer handling and function return values.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
