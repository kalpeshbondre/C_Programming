# Assignment 25 – Character Classification and Switch Case

## Description

This assignment focuses on character classification and decision-making using conditional statements and switch-case. It includes programs to check whether a character is an alphabet, uppercase alphabet, digit, or lowercase alphabet. It also includes a program to display examination timings based on a student's division using a case-insensitive switch-case implementation.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 25.1 | `ChkAlpha()` | Checks whether the given character is an alphabet (uppercase or lowercase). |
| Program 25.2 | `ChkCapital()` | Checks whether the given character is an uppercase alphabet. |
| Program 25.3 | `ChkDigit()` | Checks whether the given character is a digit (0–9). |
| Program 25.4 | `ChkSmall()` | Checks whether the given character is a lowercase alphabet. |
| Program 25.5 | `DisplaySchedule()` | Displays examination timing based on the student's division (A, B, C, or D), accepting uppercase and lowercase inputs. |

## Learning Objectives

- Understand character classification using character ranges.
- Identify uppercase and lowercase alphabets.
- Identify numeric digit characters.
- Use Boolean functions to return classification results.
- Understand and implement switch-case statements.
- Handle multiple case labels for uppercase and lowercase characters.
- Apply logical operators for input validation.
- Develop programs using modular programming and user-defined functions.
