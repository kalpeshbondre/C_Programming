# Assignment 18 – Star, Hash, and Border Patterns

## Description

This assignment focuses on developing logic-building skills through pattern printing using nested loops and conditional statements. The programs demonstrate different combinations of `*`, `#`, special characters, and numbers based on row and column positions. They also help understand matrix-based pattern logic and boundary conditions.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 18.1 | `Pattern()` | Displays an increasing `*` pattern followed by `#` symbols in each row. |
| Program 18.2 | `Pattern()` | Displays a decreasing `*` pattern followed by `#` symbols in each row. |
| Program 18.3 | `Pattern()` | Displays an increasing `*` pattern followed by `#` symbols using row and column comparison. |
| Program 18.4 | `Pattern()` | Displays a `*` border with `@` symbols inside the rectangular pattern. |
| Program 18.5 | `Pattern()` | Displays column numbers along the rectangular border and `*` symbols inside the pattern. |

## Concepts Covered

- User-defined functions with arguments and void return type.
- Nested `for` loops for row and column traversal.
- Matrix-based pattern printing.
- Conditional statements using `if-else`.
- Relational operators (`==`, `<=`).
- Logical OR operator (`||`).
- Row and column position comparison.
- Boundary condition checking (first row, last row, first column, and last column).
- Printing `*`, `#`, special characters, and numbers.
- Loop counter initialization and updation.
- Input validation using `scanf()`.
- Error handling using `fprintf(stderr, ...)`.
- Program termination using `EXIT_SUCCESS` and `EXIT_FAILURE`.

## Learning Objectives

- Understand how nested loops work in pattern printing.
- Develop the ability to represent patterns using row and column matrices.
- Apply conditions to control the output at specific positions.
- Identify boundary and inner positions in a matrix.
- Understand the use of logical and relational operators in pattern problems.
- Improve logical thinking and problem-solving skills.
- Write structured and readable C programs using user-defined functions.
