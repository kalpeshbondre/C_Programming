# Assignment 19 – Triangle and Border Patterns

## Description

This assignment focuses on developing logic for different triangle and border patterns using nested loops and conditional statements in C. It includes lower-left and upper-left triangle patterns, diagonal patterns, and hollow box patterns using `*`, `#`, `$`, and numbers. These programs help strengthen understanding of row and column relationships, matrix positions, boundary conditions, and conditional pattern printing.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 19.1 | `Pattern()` | Displays a lower-left triangle pattern using `*`. |
| Program 19.2 | `Pattern()` | Displays an inverted upper-left triangle pattern using `*`. |
| Program 19.3 | `Pattern()` | Displays a diagonal pattern using `#`, `$`, and `*`. |
| Program 19.4 | `Pattern()` | Displays a hollow box pattern with `*` on the border and main diagonal. |
| Program 19.5 | `Pattern()` | Displays an upper-right number triangle pattern. |

## Concepts Covered

- User-defined functions
- Function arguments and void return type
- Nested `for` loops
- Row and column-based pattern printing
- Triangle patterns using `*`
- Diagonal pattern printing
- Main diagonal and row-column comparisons
- Hollow box and boundary conditions
- Conditional statements (`if-else`)
- Relational operators (`<`, `>=`, `==`)
- Logical operators (`||`)
- Number pattern printing
- Loop initialization, condition, and updation
- Input validation using `scanf()`
- Error handling using `fprintf()`
- `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand nested loops for pattern printing.
- Develop logic using row and column positions.
- Learn to print different triangle patterns.
- Understand main diagonal and boundary conditions.
- Apply relational and logical operators in pattern problems.
- Improve problem-solving skills through matrix-based patterns.
- Write structured and readable C programs.
