# Assignment 21 – Number and Symbol Grid Patterns

## Description

This assignment focuses on developing rectangular grid patterns using nested loops in C. The programs demonstrate printing symbols and numbers based on row and column positions, including repeated values, ascending numbers, descending numbers, and alternating symbols.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 21.1 | `Pattern()` | Displays a rectangular grid of `*` symbols. |
| Program 21.2 | `Pattern()` | Displays column numbers in ascending order in every row. |
| Program 21.3 | `Pattern()` | Displays column numbers in descending order in every row. |
| Program 21.4 | `Pattern()` | Displays alternating `*` and `#` symbols in every row. |
| Program 21.5 | `Pattern()` | Displays the row number repeatedly across all columns. |

## Concepts Covered

- User-defined functions
- Function arguments and void return type
- Nested `for` loops
- Rectangular grid patterns
- Row and column representation
- Row-based and column-based printing
- Ascending and descending number patterns
- Even and odd column identification using the modulus operator (`%`)
- Conditional statements (`if-else`)
- Printing special symbols such as `*` and `#`
- Loop initialization, condition checking, and updation
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Program termination using `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand how nested loops generate rectangular patterns.
- Learn to control pattern output using row and column counters.
- Differentiate between row-based and column-based printing.
- Develop ascending and descending number grid patterns.
- Apply conditions to generate alternating symbols.
- Improve problem-solving skills through pattern programming.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
