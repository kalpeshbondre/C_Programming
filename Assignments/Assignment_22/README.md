# Assignment 22 – Alphabet, Number, Symbol, and Multiplication Patterns

## Description

This assignment focuses on generating different patterns using loops in C. The programs demonstrate printing uppercase alphabets, ascending and descending numbers, combining numbers with special symbols, and generating multiples of a given number using loop counters.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 22.1 | `Pattern()` | Displays uppercase alphabets in ascending order, starting from A. |
| Program 22.2 | `Pattern()` | Displays numbers in descending order, followed by `#` symbols. |
| Program 22.3 | `Pattern()` | Displays numbers in ascending order, followed by `#` symbols. |
| Program 22.4 | `Pattern()` | Displays `#` followed by an ascending number and `*` in each iteration. |
| Program 22.5 | `Pattern()` | Displays the first N multiples of 2. |

## Concepts Covered

- User-defined functions
- Function arguments and void return type
- `for` loop
- Character data type (`char`)
- Character initialization and increment
- Character printing using `%c`
- Ascending and descending number sequences
- Loop counter initialization, condition checking, and updation
- Printing multiple elements in a single iteration
- Combining numbers and special symbols
- Multiplication using loop counters
- Generating multiples of a number
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Program termination using `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand ascending and descending loop execution.
- Learn to generate consecutive uppercase alphabets.
- Develop number and symbol patterns using loops.
- Understand how to print multiple elements in each iteration.
- Generate multiples using arithmetic operations.
- Improve logical thinking and loop-based problem-solving skills.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
