# Assignment 27 – String Processing and Manipulation

## Description

This assignment focuses on string processing and manipulation in C programming. It includes programs to count capital letters, count small letters, calculate the difference between small and capital letters, check whether a string contains vowels, and reverse a string. These programs demonstrate character classification, pointer-based string traversal, Boolean operations, counters, and in-place string manipulation.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 27.1 | `CountCapital()` | Counts the number of capital letters in a string. |
| Program 27.2 | `CountSmall()` | Counts the number of small letters in a string. |
| Program 27.3 | `Difference()` | Calculates the difference between the number of small letters and capital letters in a string. |
| Program 27.4 | `ChkVowel()` | Checks whether the given string contains any vowels. |
| Program 27.5 | `Reverse()` | Reverses a string in place. |

## Concepts Covered

- String handling in C.
- Character classification using ASCII ranges.
- Counting uppercase and lowercase letters.
- Difference calculation using counters.
- Vowel identification using character comparisons.
- Boolean data type (`bool`).
- Pointer-based string traversal.
- NULL pointer checking.
- In-place string reversal.
- Character swapping using a temporary variable.
- Early return from functions.

## Learning Objectives

- Understand how to traverse strings using character pointers.
- Learn to identify uppercase and lowercase characters.
- Develop logic to count different categories of characters.
- Perform arithmetic operations on character counts.
- Check whether a string contains specific characters.
- Understand Boolean return values.
- Learn to reverse strings without using an additional character array.
- Improve problem-solving skills through string manipulation.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`, `stdbool.h`
- **Compiler:** GCC
