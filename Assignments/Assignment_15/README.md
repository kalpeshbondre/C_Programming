# Assignment 15 – Basic Mathematical Operations and Conditional Checks

## Description

This assignment focuses on basic mathematical operations and conditional checks using user-defined functions in C. The programs perform operations such as accepting and displaying a name, checking whether a number is greater than 100, checking equality between two numbers, calculating the multiplication of three numbers while ignoring zero values, and calculating percentage.

## Programs List

| **Program**  | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 15.1 | `Display()` | Accepts and displays the name entered by the user. |
| Program 15.2 | `ChkGreater()` | Checks whether a given number is greater than 100. |
| Program 15.3 | `ChkEqual()` | Checks whether two given numbers are equal. |
| Program 15.4 | `Multiply()` | Calculates the multiplication of three numbers while ignoring zero values. |
| Program 15.5 | `Percentage()` | Calculates the percentage based on total marks and marks obtained. |

## Concepts Covered

- User-defined functions
- Function arguments and return values
- Character arrays and strings
- String input using `scanf()` scanset
- Boolean data type using `stdbool.h`
- Conditional statements (`if-else`)
- Comparison operators (`>`, `==`)
- Multiplication of numbers
- Handling zero values in mathematical operations
- Floating-point arithmetic
- Type casting
- Percentage calculation
- Input validation using `scanf()`
- Error handling using `fprintf()`

## Learning Objectives

- Understand how to accept and display strings in C.
- Implement user-defined functions with different return types.
- Use Boolean values to perform conditional checks.
- Compare two numbers using relational operators.
- Perform multiplication while following specified conditions.
- Understand floating-point division and type casting.
- Calculate percentages using mathematical expressions.
- Improve logical thinking and problem-solving skills.
- Understand the use of function arguments and return values.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`, `stdbool.h`
- **Compiler:** GCC
