
# Assignment 13 – Digit Operations and Mathematical Calculations

## Description

This assignment contains C programs based on digit extraction, digit classification, frequency counting, multiplication, and summation. The programs use loops, conditional statements, and arithmetic operators to perform different operations on individual digits of a given number.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 13.1 | `CountEven()` | Counts the frequency of even digits in a number. |
| Program 13.2 | `CountOdd()` | Counts the frequency of odd digits in a number. |
| Program 13.3 | `CountRange()` | Counts the frequency of digits strictly between 3 and 7. |
| Program 13.4 | `MultDigits()` | Calculates the product of all digits in a number. |
| Program 13.5 | `CountDiff()` | Calculates the difference between the sum of even and odd digits. |

## Concepts Covered

- User-defined functions
- Function arguments and return values
- Digit extraction using modulus operator (`%`)
- Digit removal using division operator (`/`)
- `while` loop
- Conditional statements (`if-else`)
- Even and odd digit identification
- Range checking using logical AND (`&&`)
- Frequency counting using counter variables
- Multiplication of digits
- Summation of even and odd digits
- Difference between two sums
- Negative number handling
- Input validation using `scanf()`
- Error handling using `fprintf()`

## Learning Objectives

- Understand how to extract and process individual digits of a number.
- Develop logic to identify even and odd digits.
- Count digits that satisfy specific conditions.
- Apply range checking using relational and logical operators.
- Calculate the product of individual digits.
- Calculate separate sums of even and odd digits.
- Find the difference between two calculated sums.
- Improve problem-solving skills through digit-based operations.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`
- **Compiler:** GCC
