# Assignment 24 – String Searching and Manipulation

## Description

This assignment focuses on string searching, character frequency counting, occurrence indexing, and string manipulation using character pointers. The programs perform operations such as checking whether a character exists, counting its occurrences, finding its first and last occurrence, and reversing a string in place.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 24.1 | `ChkChr()` | Checks whether a given character is present in a string. |
| Program 24.2 | `CountChar()` | Counts the frequency of a given character in a string. |
| Program 24.3 | `FirstChar()` | Returns the index of the first occurrence of a character in a string. |
| Program 24.4 | `LastChar()` | Returns the index of the last occurrence of a character in a string. |
| Program 24.5 | `StrRevX()` | Reverses a string in place. |

## Concepts Covered

- Character pointers and string traversal.
- Constant character pointers using `const char *`.
- NULL pointer checking.
- Boolean data type using `stdbool.h`.
- Character comparison and searching.
- Linear search technique.
- Character frequency counting.
- Finding first and last character occurrences.
- Index tracking using counters.
- Early return from functions.
- Reversing strings in place.
- Swapping characters using a temporary variable.
- Array indexing and pointer arithmetic.
- Time and auxiliary space complexity.

## Learning Objectives

- Understand string traversal using character pointers.
- Implement character searching operations.
- Count occurrences of specific characters in a string.
- Find the first and last positions of a character.
- Understand the difference between searching and frequency counting.
- Reverse a string without using additional string arrays.
- Apply pointer arithmetic and array indexing.
- Improve problem-solving skills through string-based operations.

## Technologies Used

- **Programming Language:** C
- **Header Files:** `stdio.h`, `stdlib.h`, `stdbool.h`
- **Compiler:** GCC
