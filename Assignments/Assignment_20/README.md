# Assignment 20 – Diagonal and Hollow Box Patterns

## Description

This assignment focuses on developing logic for diagonal and hollow box patterns using nested loops and conditional statements in C. It includes anti-diagonal patterns, hollow box patterns, and combinations of `*`, `#`, `@`, `$`, and numbers. These programs help strengthen understanding of row and column relationships, diagonal positions, boundary conditions, and matrix-based pattern printing.

## Programs List

| **Program** | **Function Name** | **Description** |
| ------------ | ----------------- | --------------- |
| Program 20.1 | `Pattern()` | Displays a grid of `*` with `#` on the anti-diagonal. |
| Program 20.2 | `Pattern()` | Displays an anti-diagonal pattern using `*`, `#`, and `@`. |
| Program 20.3 | `Pattern()` | Displays a hollow box with `*` on the boundary and anti-diagonal. |
| Program 20.4 | `Pattern()` | Displays a hollow box with `*` on the boundary and anti-diagonal, `#` before the anti-diagonal, and `$` after it. |
| Program 20.5 | `Pattern()` | Displays a hollow box with column numbers on the boundary and main diagonal. |

## Concepts Covered

- User-defined functions
- Function arguments and void return type
- Nested `for` loops
- Row and column-based pattern printing
- Main diagonal and anti-diagonal patterns
- Hollow box patterns
- Boundary conditions
- Conditional statements (`if-else`)
- Relational operators (`==`, `<`)
- Logical operators (`||`)
- Printing symbols (`*`, `#`, `@`, `$`)
- Number pattern printing
- Loop initialization, condition, and updation
- Input validation using `scanf()`
- Error handling using `fprintf()`
- `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand diagonal positions in matrix-based patterns.
- Differentiate between main diagonal and anti-diagonal conditions.
- Develop logic for hollow box patterns.
- Apply boundary conditions using row and column comparisons.
- Use multiple conditional statements to print different symbols.
- Understand how nested loops control pattern printing.
- Improve logical thinking and problem-solving skills in C.
