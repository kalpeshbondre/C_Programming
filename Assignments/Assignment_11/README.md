
# Assignment 11 – Range Operations

## Description

This assignment contains C programs based on range operations using loops, conditional statements, and mathematical calculations. The programs accept a range from the user and perform operations such as displaying numbers in ascending and reverse order, displaying even numbers, calculating the sum of all numbers, and calculating the sum of even numbers within the given range.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| Program 11.1 | `RangeDisplay()` | Accepts a range and displays all numbers between the given starting and ending values. |
| Program 11.2 | `EvenRangeDisplay()` | Accepts a range and displays all even numbers within the given range. |
| Program 11.3 | `RangeSum()` | Accepts a positive range and returns the addition of all numbers within the given range. |
| Program 11.4 | `RangeSumEven()` | Accepts a positive range and returns the addition of all even numbers within the given range. |
| Program 11.5 | `RangeDisplayRev()` | Accepts a range and displays all numbers in reverse order between the given starting and ending values. |

## Concepts Covered

- User-defined functions
- Function arguments and return values
- For loop
- Conditional statements (`if-else`)
- Range-based operations
- Ascending and descending iteration
- Even and odd number identification
- Modulus operator (`%`)
- Summation of numbers
- Input validation using `scanf()`
- Error handling using `fprintf()`
- Return values for invalid ranges
- Loop counter initialization and updation

## Learning Objectives

- Understand how to perform operations within a given range.
- Learn to display numbers in ascending and reverse order using loops.
- Identify and process even numbers within a range.
- Calculate the sum of numbers using iterative logic.
- Understand how to return calculated results from user-defined functions.
- Apply conditional statements to validate ranges.
- Improve problem-solving skills through range-based programming exercises.
