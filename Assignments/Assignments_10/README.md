# Assignment 10 – Mathematical and Unit Conversions

## Description
This assignment contains C programs that perform mathematical calculations and unit conversions using user-defined functions. It covers area calculations for geometric shapes, distance conversion, temperature conversion, and area conversion.

## Programs List

| Program | Function Name | Description |
|---|---|---|
| 10.1 | `CircleArea()` | Calculates the area of a circle using its radius. |
| 10.2 | `RectArea()` | Calculates the area of a rectangle using its width and height. |
| 10.3 | `KMtoMeter()` | Converts distance from kilometres to metres. |
| 10.4 | `FhtoCs()` | Converts temperature from Fahrenheit to Celsius. |
| 10.5 | `SquareMeter()` | Converts area from square feet to square metres. |

## Concepts Covered

- User-defined functions
- Function parameters and return values
- Mathematical calculations
- Area calculation of geometric shapes
- Distance, temperature, and area conversions
- Use of constants (`const`)
- Integer and floating-point data types
- Input handling using `scanf()`
- Input validation
- Conditional statements (`if`)
- Formatted output using `printf()`
- Error handling using `fprintf()`
- Use of `EXIT_SUCCESS` and `EXIT_FAILURE`

## Learning Objectives

- Understand how to create and call user-defined functions.
- Perform mathematical calculations using C.
- Implement different unit conversion formulas.
- Understand the use of `int`, `float`, and `double`.
- Use constants for fixed conversion values.
- Apply input validation and basic error handling.
- Improve problem-solving and logical thinking skills.
